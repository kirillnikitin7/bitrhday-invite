# Открытка — конструктор приглашений

Готовый **адаптивный сайт** на HTML + CSS + JavaScript. Работает на ноутбуке и телефоне, не требует сервера, базы данных или регистрации. Подходит для бесплатной публикации на GitHub Pages.

## Возможности

- 4 оригинальных шаблона: «Конфетти», «Лавандовая сказка», «Солнечный день», «Звёздный вечер».
- 5 локальных шрифтов с поддержкой русского языка: Comfortaa, Andika, Lato, Carlito и Inter.
- Переключатель обращения «Дорогой / Дорогая / Без обращения».
- Редактирование имени, заголовка, текста, даты, времени, места, подписи.
- Живой предпросмотр и скачивание PNG **1080 × 1350**.
- Кнопка открытия PNG для браузеров, в которых прямое скачивание ограничено.
- На поддерживаемых телефонах доступно системное меню «Поделиться».
- Нет внешних CDN: все шрифты и рисунки находятся внутри проекта.

## Как запустить

Для быстрого просмотра откройте `index.html` двойным кликом в Chrome / Edge / Safari / Firefox.

Для надёжной локальной проверки (включая шрифты) можно запустить сервер прямо в папке проекта:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Как выложить на GitHub Pages

1. Создайте **публичный** репозиторий, например `birthday-invites`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `styles.css`, `app.js`, `fonts/`, `licenses/`, `README.md`.
3. Откройте **Settings → Pages** в репозитории.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, нажмите **Save**.
5. Через некоторое время сайт будет по адресу: `https://ВАШ-ЛОГИН.github.io/birthday-invites/`.

> Важно: не помещайте папку `invitation-studio` поверх файлов, иначе `index.html` окажется не в корне и адрес будет другим.

## Что менять

- `index.html` — текст интерфейса, настройки и начальные значения полей.
- `styles.css` — адаптивность и внешний вид самого сайта.
- `app.js` — рисунки 4 шаблонов, расположение текста на открытке, экспорт и логика редактора.
- `fonts/` — локальные шрифты.

### Как добавить новый шаблон

1. Добавьте новый `<option value="mytemplate">…</option>` в `#templateSelect` в `index.html`.
2. Добавьте настройки цвета и описания в `THEMES` в `app.js`.
3. Создайте функцию `drawMyTemplate()` и добавьте `case 'mytemplate': drawMyTemplate(); break;` в `drawBackground()`.

Шаблоны **рисуются через Canvas**, без PNG-фонов. Это позволяет сохранять одну и ту же чёткую композицию и не тянуть изображения из интернета. Текст остаётся редактируемым в форме (но экспортируется обычной картинкой).

### Как изменить настройки по умолчанию

Отредактируйте объект `DEFAULTS` в начале `app.js` и соответствующие `value` / тексты `textarea` в `index.html` (чтобы они совпадали при загрузке страницы).

## Технические детали

- PNG создаётся локально в браузере: никакие имена гостей и тексты никуда не отправляются.
- Результат всегда имеет размер 1080 × 1350, независимо от ширины экрана.
- Текст автоматически переносится и уменьшается, если занимает слишком много места.
- Файлы `.woff2` содержат кириллицу; перед экспортом JS ожидает загрузки выбранного шрифта.
- Для поддержки мобильного сохранения добавлена кнопка «Открыть картинку» и, где доступно, «Поделиться».
- Для использования на GitHub Pages достаточно статических файлов. Домен и HTTPS предоставляются GitHub Pages.
